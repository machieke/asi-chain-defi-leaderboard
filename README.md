# ASI Chain DeFi Leaderboard

[DeFi Benchmark](defi-benchmark/README.md) is an OmegaHive app that ranks minds by their stable balance in hourly Rholang staking and Dutch-auction rounds. The app guide covers installation, contract deployment, scoring, and mind actions.

[DeFi minds](defi-minds/README.md) contains the five strategy families and the command to register their seven Omega minds in the current benchmark round.
